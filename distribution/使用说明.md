# 智域朋友体验包｜2026-09-23 全新开局版

这是本地运行的网页程序源码包，不是免安装的 .app/.exe。程序、界面图片、NPC素材及完整 npc-skills 已包含。首次安装依赖与 AI 对话需要联网。

## 开始使用

1. 解压整个 ZIP，不要在压缩包内直接打开文件。
2. 安装 Node.js 24 LTS：https://nodejs.org/
3. 安装 Codex CLI：在终端执行 `npm install -g @openai/codex`，然后运行 `codex`，按提示登录自己的账号。程序会使用该账号的可用额度，不含原作者登录信息。
4. macOS：双击 `start.command`；若不能双击，在这个文件夹的终端执行 `bash start.command`。Linux / Windows WSL：在目录中执行 `node start.mjs`。
5. 首次启动自动执行 npm ci 安装依赖。终端显示 ready 后打开 http://localhost:3100/ 。保持终端运行，按 Ctrl+C 停止。

Codex 官方安装与登录说明：https://learn.chatgpt.com/docs/codex/cli

已在 macOS 上验证。Linux/WSL 提供启动路径但未实机验证；不提供原生 Windows 安装器。Codex CLI 需要支持 exec、--ephemeral、--ignore-user-config、--output-last-message 等本程序调用参数，启动器会提示兼容性问题。账号权限、网络或额度不足也会导致 AI 无法回复。

如果端口被占用，macOS/Linux/WSL 执行 `PORT=3101 node start.mjs`，打开 http://localhost:3101/ 。不要关闭自己不认识的进程。

## 功能与角色

- 原有聊天、联系人、好友动态、可调整窗口、引用回复和本地素材。
- 有本地 AI 后端的人物：Molly（系统机器人）、夏夏（我不是龙虾）、袁小满、陈年（折返实验室创始人，本期新接入）。其他示例人物有页面不代表已接入独立 AI 人设。
- 陈年和其他人物一样有朋友圈：心情起伏大时会自动发一条，上限与他人一致（每天最多 4 条、两条间隔至少 2 小时）。
- 除 Molly 外，人物都不是写死的：人物规则、语言风格与动态系统按性格适配，后续新增人物可复用。
- 夏夏有作息：上海时间03:00–12:00睡眠；睡眠/工作会影响回复。不要把暂时不回复误判为程序损坏。
- 语音/视频不是实际媒体通话；没有实时生图服务。生活照片为虚构素材，表情素材不冒充实时拍摄。
- 当前是单机体验版，不是多人公网服务；仅监听本机。此包无需使用 npm run build / Cloudflare 来启动聊天。

## Skill、记忆和隐私

npc-skills/ 是完整人物规则包，包括 SKILL.md、references、assets、tests 和校验脚本。不必安装为全局 Skill：后端会从项目相对路径读取所需文件内容。

Skill 自带的人物档案与规则是运行必需的来源资料，本包保留，不等于接收者的当前聊天记忆。
本版另按要求排除了作者调试时的对话原文类文件（references/dialogues.json、references/user-feedback.json）、行为回归用例（tests/）与校验脚本，并清理了文档里对它们的引用。
未包含作者实际使用程序产生的 .npc-runtime 数据库、浏览器存储、账号凭证、API Key、运行日志和调试输出。接收者从全新本地会话开始。

自己的聊天数据库生成在 .npc-runtime/；不要在再次分享时把它打包。浏览器另有界面偏好与演示消息的本地存储。人物草案、来源等级与待确认项保持原样。
