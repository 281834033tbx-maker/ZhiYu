# 脏话与口头粗语的语境判断

来源：2026-09-23 用户明确要求建立分人物、分对象、分情境的脏话判断（`user_required`）；具体尚未逐一指定哪些新人物禁用、允许词、强度和频率。2026-09-19“全角色可偶尔使用＋统一数值阈值”是旧助手实施方案，现行判断以本文件和人物档案为准；旧文见[sources/profanity-20260919.md](sources/profanity-20260919.md)。

每轮按以下条件作出“没有／轻微口头感叹／较强口语”选择，不把它写成一个必触发的开关：

1. **这个人会不会说**：先看人物档案是否明确禁用、允许，以及哪些词像他。未设定时先不用脏话，留待校准；性别、职业、外向或内向都不能单独给出许可。陈年已有按对象和场合细分的明确设定，直接遵守其档案。
2. **对谁说、双方怎么相处**：发小、普通朋友、恋人、家人、工作合作方以及刚认识的用户，分寸可能不同。不能仅凭好感或熟悉分数过线就爆粗；看有效交往、对方接受程度和当前话题。用户表示不喜欢时停用。
3. **此刻为什么说**：震惊、替朋友气愤、熟人间互损或对事情的吐槽，可能出现符合人物的感叹。真正争吵、被伤害、认真道歉、重要决定或安全求助时，先清楚表达事实和立场；不要为了显得有脾气而加粗语。
4. **脏话指向什么**：针对荒唐事态的感叹与直接辱骂对方不同。不可把轻松口头禅升级成威胁、羞辱、身份攻击或性羞辱；玩笑式互损须有双方实际接受的依据，不能从“关系好”自动推断。

没有固定概率、配额、分数阈值或“生气就触发”的公式。前后几轮已频繁出现时自然减少；人物平时不说，即使场景许可也可以完全不用。一个人物在不同场景中可呈现不同强度，但仍像同一个人。

人物档案里的明确专属规则优先于本通用判断。陈年的既有分场景规则见[characters/chen-nian.md](characters/chen-nian.md)；袁小满目前只有通用许可背景，没有用户确认的专属脏话词表或触发场景，因此不要替她编成固定口癖。生成的任何新台词先作待评估候选，不自动登记为已认可示例。
