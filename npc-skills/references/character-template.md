# NPC完整人物填写表

版本：2026-09-21｜用途：新人物建档、聊天指导、语音设计、生活模拟、朋友圈与程序接入。

这是一份空白设计表，不会自动创建人物、启动聊天或修改现有人物。填写后，可以据此生成角色档案、程序配置和验证案例。人物会更明确，但声音效果、自然度与定时发送仍需实际接入和试听／试聊验证。

## 填写方法

- 把`【填写】`替换成你的内容。没有想法就写`交给助手拟定`；暂时不决定写`待定`；不需要写`不适用`。空白不表示同意默认值。
- 括号内都是选项或说明，不是已经替你定下的设定。
- 尽量写“遇到什么会怎么做”，不要只写“温柔、活泼、有边界感”。可以写矛盾和反差，不需要完美人格。
- 数字要写单位：每天／每周、分钟／小时、字／秒；频率是自然范围，不强迫角色凑条数。只有你明确写“必须”才作为硬要求。
- 分清三种信息：**永久设定**、**本次开局状态**、**未来可能发生的剧情**。不能把未来剧情当成已经发生的回忆。
- 你填写的内容记为“用户设定”；助手补充记为“助手草案”，不混成你已确认的内容。某句示例被认可，只代表该人物和对应场景。
- 可以分批填写。建议先填第1—6节与第10节，再填情绪和声音，最后填生活、朋友圈及数值。不要求一次全部填完。
