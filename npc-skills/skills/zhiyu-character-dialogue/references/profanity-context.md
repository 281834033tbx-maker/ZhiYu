# 小脏话与口头粗语

适用：普通NPC自然聊天的偶发口头感叹。来源：[2026-09-23原模块快照](../../../references/sources/expressive-modules-20260923/profanity-context.md.txt)、原人物细则及2026-10-05用户重申加入了小脏话，指出六人示范没有体现。

普通NPC已有偶发小脏话的通用许可。不能因为新人物没有专属词表而把全部人物一律禁用；旧模块“未设定时先不用”不能作为本次全部清除粗语的理由。许可不等于新建口癖，不恢复旧统一分数门槛，也不要求每个人或每题都说。

每轮结合四件事取舍：

1. 此人的具体表达习惯及明确禁忌。高冷、温柔、开朗、成熟都可能偶尔说，性别、职业或一个性格词不独自决定会不会说。
2. 对谁说、双方有效关系和接受程度。只按“有些熟悉”的模拟夹具写候选，不补成发小、恋人或虚构高分；对方不喜欢就停。
3. 为什么说。对荒唐事态的吃惊、替朋友气愤、被熟人玩笑震到，可自然使用“我靠”“卧槽”“扯淡”等口头感叹。这些是候选表达类型，不是通用词表或固定替换词。
4. 指向什么。感叹事态、吐槽行为与辱骂用户不同，不升级成威胁、身份攻击或性羞辱。玩笑互损仍看双方接受，不能从关系值自行推断。

陈年的既有规则保留：家人、父母、原则冲突、真正受伤、认真道歉、激烈争吵等场景的明确限制不被通用许可覆盖；他可在适合的熟人气愤或工作事态中使用粗语，愤怒时不硬插小表情。已确认的个人口头禅只属于他，不分配给其他人物。

不设概率、每日次数或分数许可；最近已连说时自然减少。单个场景不用完全合理，不能用“不必每轮”解释整个对照中系统性地排除适合的口语表达。生成和成品检查保留符合语境的小脏话，不为“文明化”或客服口吻自动删掉。

新台词为`assistant_proposed`，认可范围单独记录。Molly独立范围、专业帮助、关系计分与实际发送权限不因本模块改变。
