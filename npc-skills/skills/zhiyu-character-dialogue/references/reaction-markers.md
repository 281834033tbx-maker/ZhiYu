# 即时符号反应：问号与省略号

适用：普通NPC的惊讶、疑惑、无语和熟人玩笑。来源：2026-09-23用户的独立问号规则，[原模块快照](../../../references/sources/expressive-modules-20260923/reaction-markers.md.txt)和[旧路由](../../../references/sources/expressive-modules-20260923/dialogue-routing.md.txt)；2026-10-05用户再次明确要求独立“？”、“...”的小梗。后者作为本轮明确补充，不声称旧文件已有独立省略号专项细则。

`？`、`？？？`、`?`、`...`或`…`可以单独成为一条消息，是人物当下的交际反应，不必补成完整句。问号可表示没听明白、惊讶、觉得离谱或玩笑式质疑；省略号可表示短暂无语、被噎住或对熟人玩笑的停顿。含义由前后文、关系与人物决定，不能看到一个符号就自动判生气。

先看这个人此刻真正的反应，再选独立符号、短词或完整句。高冷也可直接发问号，温柔也可被震到；性格标签不固定符号频率。同一人物可在不同场合采用不同方式，允许一句反应就停。

- 符号已经传达意思时，可以到此为止。需要态度、关键询问或帮助时，再自然发后续消息；不自动解释符号含义。
- 独立符号是`messages`的一项，不与正文粘成一段。普通问句末尾有问号不等于独立即时反应。
- 认真受伤、道歉、真实求助或重要决定需要必要的信息与支持，符号不能独自代替它们。用户怀疑不被理睬时尤其留意省略号可能被误读为嫌弃或冷处理。
- 不每轮插入、不按人格配额发、不把多种符号串成固定开场，也不靠连续省略号或叹号装出情绪。

本轮六人示范可按语境选用，不因新人物没有专属标点表而整批排除。具体新用法仍是待用户点评的候选，不反写成永久口癖；已有明确人物禁忌与用户边界继续优先。Molly继续独立规则，本模块不授权发送消息、改关系或生成新记忆。
