# 融合摄影流程

来源：iphone-photo 的拍摄与结构化提示方法，以及 photosession 的细节卡、光照材质和自检。用于每次 NPC 生活照生成；人物不存在的字段直接省略。

## 1. 明确画面与参考用途

区分新图、参考引导和局部编辑。分别标明身份、姿态、服装、物件、环境参考；编辑时列出保持项和允许变化项。风格相似可依赖文字；特定物件保真需要可用的物件参考与文字细节，不能承诺像素级复刻。遮挡和看不清之处保留不确定性。

## 2. 组织拍摄方案

按顺序组织：画幅与裁切 → 动作/表情/手指接触 → 头发 → 皮肤纹理 → 妆容/嘴唇 → 重点物件细节 → 场景光源 → 光在材质上的响应 → 背景 → 相机位置/镜头/焦点 → 统一色彩 → 本场景需避免的问题。无人物时省略人物相关项，不凭空添加人、首饰或道具来凑字段。

选择一个镜头：普通主摄约24mm感用于日常；空间狭窄或刻意夸张近景可用约13mm超广角感；远距离旁观可用约77mm长焦感。自拍先满足持机距离和前摄/镜子逻辑，不强行套后置超广角。默认3:4，用户指定优先；9:16适合全身和纵深场景。写清拍摄距离和对焦主体，不能同时要求所有景物锐利和强烈浅景深。

手机HDR、局部细节融合只作视觉目标，不伪造设备或RAW元数据。保留背景环境和适度曝光差异；用少量合理的偏心、边缘截断、轻微运动、细微数字噪声体现抓拍。不叠加胶片颗粒、影棚打光和商业磨皮。

## 3. 重点物件细节卡

只有画面确实包含并需要保真的物件才填写：类别；材质/本色；表面处理；宝石有无、数量、切割及颜色；镶嵌方式；轮廓与厚度；辨识特征；相对手/脸/腕的大小；受光位置；佩戴或摆放的位置与朝向。非珠宝的宝石/镶嵌项不适用，不编造。

把细节写成连续一句，紧接光照作用。戒指不能只写“金色”，需分清黄/玫瑰/白色金属，但不能从模糊图片推断纯度、品牌或材质鉴定。手握餐具、清洁工具、手机时核对受力、握持位置、指节和遮挡。

## 4. 光照与材质统一

每个光源写清方向、软硬、色温及作用范围。混合街灯可以存在；同一位置的脸、金属与餐盒不能被互不相干的假光源照亮。对应描述高光落点、反射环境、背光侧层次，以及宝石在方向性光下才有的闪点。

金属反射受环境影响，同时保留本色；布料随折皱形成柔和明暗；湿发高光沿发丝；嘴唇局部高光与纹理并存；皮肤保留自然毛孔、绒毛、色差，避免整脸塑料光泽。玫瑰色金属可有暖高光与较冷暗部，白色金属不染成黄色，宝石不无限增加。没有这些材质时不添加。

颜色冲突优先保护材质本色，其次保持光源物理一致，最后减少调色强度。相机段描述光学，调色段描述色彩，不叠加互相冲突的胶片/LUT与“绝对中性”。

## 5. 生成前后自检

生成前独立复读提示词：镜头与持机位置是否匹配、画幅是否清楚、动作是否可信、参考身份是否保持、物件细节是否有根据、皮肤是否自然、材质反射是否服从场景、色彩是否冲突、是否引入用户未要求的故事。发现矛盾先修正再调用生图。

生成后若当前工具能查看结果，按同一清单检查手部、脸、物件位置与数量、光影、背景和多余文字。明显错误最多针对性修正一轮；工具不能查看时不能声称已完成视觉验收。后台自动流程不需要每张都让用户确认，也不能在没有检查工具时阻塞交付。生图质量仍需用户反馈，不宣称自动检查能保证完全真实。

## 结构化提示词模式

仅当用户要求导出提示词/JSON时，使用 meta_data（style、aspect_ratio）、prompt_components（subject、environment、lighting、camera_gear、processing、imperfections、detail、light_material）、full_prompt_string、negative_prompt。full_prompt_string 必须独立完整；参考用途写入subject。技术术语可以用英文，图片中的指定文字保持原语言。程序正常生图仍遵守外层返回的path/error协议，不输出这份提示词JSON代替图片。

## 6. 成年女性腿照的修长构图（2026-09-19）

用户要求：在既有正常着装、非露骨的腿照风格中，让腿视觉上更修长、有吸引力。以下为查阅摄影资料后的实施建议，不是修改人物真实身材，也不是已验收图像。仅在腿部/穿搭照片适用，不把所有女角色照片都拍成腿照。

- 全身或对镜构图：手机主摄约24–28mm感即可，适度降低机位，避免从头顶明显向下俯拍全身；优先接近水平，按构图轻微调整，避免极端仰拍和裙底视角。镜自拍降低机位必须符合本人手臂够得到的高度，不凭空出现第二个摄影者。
- 竖幅给腿留出连续空间，脚靠近画面下缘但保留少量余地，避免切断脚尖；头和脸不要挤到广角边角。镜框、椅腿及门框保持直，不靠弯曲背景“拉长”。
- 坐地/坐椅：一条腿自然向画面下方或对角线伸展，另一条适度屈膝；避免双腿都紧缩在身前。脚踝自然舒展、脚尖轻轻延伸，不绷成不可能的角度。腿可以略靠近镜头，但脚不能近到显得异常巨大。
- 本人俯拍腿部是另一种真实持机方式，不套“全身低机位”；靠向前伸腿、连续腿线与竖向/对角线构图实现修长感。坐地镜自拍、抬腿坐椅也不强求每次都完整露出双腿。
- 保持日常短裤或裙装与既有场景连续，用姿势、柔和侧光和衣料层次表现性感与松弛。不改变角色身高、骨架、体重设定，不瘦成纸片腿，不把腿或脚机械拉伸，不制造左右腿长短不一、膝盖错位、多肢或镜像不一致。

生成后重点检查：镜头位置是否能实际拍到、镜面反射、腿脚比例、两膝和脚踝、脚尖裁切、背景直线。构图效果尚需实际生成后视觉验收，不能仅凭提示词宣称达标。
