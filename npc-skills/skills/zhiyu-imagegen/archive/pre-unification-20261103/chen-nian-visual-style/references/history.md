# 陈年视觉系统版本沿革

本文件保存视觉规则和素材的形成过程。它是追溯记录，不是当前生成提示；当前规则以 `identity-and-body.md`、`selfie-style.md` 和 `moments-style.md` 为准。

## 1. 人物基础外形

- 角色事实：陈年28岁、约183cm，长期运动、肩背舒展，短发，眉眼利落、五官立体，笑时右侧有浅酒窝。
- 日常服装：有质感的旧T恤、宽松衬衫、牛仔裤、干净球鞋；正式场合为剪裁合身的西装。
- 身体的具体体重没有定稿，因此不在图片提示里虚构数字。

## 3. 朋友圈与分享欲补充｜2026-09-19

用户要求：当前期熟悉度、好感度等多数积极数值稳定提升约30点时，陈年会主动分享正在做什么；照片必须是现实感的半失败随手拍，自拍只偶尔出现，不能完美。

实现记录：

- 生成 `share-workdesk-v1.png`，作为普通生活照优先的现行样张。
- 生成 `share-rainy-selfie-v1.png`，作为后置、低频的直男自拍。
- 宿主程序使用“至少四项积极值提升30点且好感达标”的门槛，每天最多一轮、最短36小时、素材不重复。此数值逻辑不是图片本身的属性。
- 第三张独立自拍尝试未成功产出，因此没有伪造文件，也不进入素材池。

## 4. 雨夜自拍少年感修订｜2026-09-19

用户反馈：首版雨夜自拍很真实，但脸稍显沧桑，可能来自抬头纹；陈年的少年感应该很强。

修订内容：

- 减弱额头纹、深折痕、眼下凹陷、重眼袋和干涩老态。
- 增加年轻成年人的自然面部饱满度与清醒松弛感。
- 保留硬眉骨、颧骨平面、直鼻骨、扎实下颌、真实毛孔、小痣和自然不对称。
- 保留雨夜路边摊、手指遮角、歪构图、旧手机柔糊、运动模糊、过曝和非精修质感。

结果：

- `assets/history/share-rainy-selfie-v1-superseded.png` 保留为修订证据，禁止继续发送或参与生成。
- `assets/examples/share-rainy-selfie-v2.png` 成为当前现行雨夜自拍样张。
