# 聊天截图

聊天截图是图片资产，但不是生成式图片。使用发布动态的 NPC 自己看到的真实聊天界面作为唯一视角。

## 数据来源

- 只接受该 NPC、本用户、当前有效分支、已经送达且连续的真实消息 ID。
- 原文、顺序、发送者和时间来自程序记录；不得润色、重排、删改关键否定或另造内容。
- 隐藏真实昵称、账号、通知、输入框和其他会识别用户身份的信息。

## 视角与组件

- NPC 自己的消息在右侧，不显示 NPC 头像。
- 用户消息在左侧，显示当前应用内用户头像。
- 裁剪只保留所选聊天内容；不包含顶部会话头像、昵称、状态或导航栏。
- 已读双对号只附在 NPC 自己发送的右侧消息上。
- 必须复用宿主聊天页同一套头像、分组、气泡、时间、间距和回执组件。图标、尺寸、线宽、颜色与对齐均来自真实组件，不用文字、emoji、近似 SVG 或生成模型替代。

## 验收

返回前逐项确认：消息来源有效且连续；NPC 在右、用户在左；NPC 无头像、用户有头像；没有顶部人物信息；已读回执只在 NPC 消息；裁剪内无隐私泄露。任一项失败都返回 `status=failed`，不发布。
