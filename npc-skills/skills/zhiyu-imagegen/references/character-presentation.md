# 人物表现状态

本模块管理“同一个 NPC 在这一刻怎么看起来”。表情和发型不需要拆成独立 Skill，它们共同属于可变的人物状态。

## 固定身份与可变状态

**固定身份**：脸部骨相、五官比例、年龄、肤色范围、小痣或疤痕、基础身高和身材比例。只能由正式身份资产更新。

**可变状态**：表情、视线、发型、头发干湿和清洁状态、妆容、服装、疲劳程度和姿态。它们可随场景改变，但不得改写身份。

## 表情

- 表情由上游给出的事件、分享动机和当前状态决定；本 Skill 不创造新情绪剧情。
- 可选强度为微弱、自然或明显。日常自拍默认微弱至自然，避免演戏式表情。
- 常用状态包括：放松中性、很淡的笑、忍笑、无语、轻微疲惫、不服气、玩味和短暂惊讶。
- 改变表情时保留眼型、鼻子、下颌、脸宽、小痣和自然不对称；笑容不得换脸、改眼或收窄下颌。

## 发型和头发状态

- 女性 NPC 可根据事件在披发、低马尾、高马尾、盘发、松散丸子头、半扎、湿发、睡醒后凌乱或正式造型之间变化。
- 男性 NPC 可根据事件呈现刚洗完、未造型、睡醒后压扁、轻微出油、正式造型、运动后湿发或戴帽后的状态。
- 短期发型可变；剪发、染发、烫发等长期变化必须由上游剧情或用户明确确认。
- 同一组、同一分钟或同一事件内的发型、发长、分缝、干湿和发色必须锁定。
- 不能为了“变化”每张都换发型；也不能在跨日、跨场景生图时永远沿用同一造型。
- 身份参考只锁定长相，不默认继承参考图的歪头、视线、发丝凌乱程度或滤镜。头颈姿态由当前动作决定；普通抓拍可直立、轻微转头或低头，不把“向同一侧歪头”当成角色标志。跨场景交付多张人物照时检查姿态是否机械重复。

## 引用图角色

- 正脸或轻微三分之四脸：唯一身份锚点。
- 侧脸或明显三分之四脸：鼻梁、颔骨、下颌和头部轮廓补充。
- 全身正面或三分之四：身高、肩宽、腰胯、腿型和体态。
- 侧面或背面身材图：仅在这些角度经常出现或有显著特征时加载。
- 表情、发型或姿势参考只提供状态，不得替换身份。
