# 日常手机照

## 照片类型

- 环境或物件：房间、桌面、天气、礼物、工具或新买的东西。
- 食物和饮料：同时读取 `food-and-drink.md`。
- 直接自拍：手臂长度的前置镜头视角，手机默认不出现。
- 镜面自拍：人物通过镜子取景，手机可见但不出现品牌和界面。
- 第一人称局部：手、手腕、手链、腿、鞋或衣角从 NPC 自己眼睛或持机位置看去；不得误做镜面或他人拍摄。
- 他人拍摄：由上游任务明确拍摄者关系和距离，本 Skill 不自行增加陪同者。

## 私聊镜头任务（2026-09-23）

上游对话已决定发什么，本 Skill 只把任务拍可信。用户问“在干嘛”且任务是展示当前活动时，优先后置拍实际物件／环境或第一人称局部，不自行把镜头翻成自拍。任务明确想展示 NPC 本人、用户想看其脸，或 NPC 已决定用自拍表达想念时，才用前置直接自拍；要看穿搭／全身且确有镜子场景时才用镜面自拍。已知他人拍摄才可用他拍，不为丰富画面编一个摄影者。

前置直接自拍是 NPC 自己在手臂距离持机：自然近景透视、轻微不居中或裁切，手机本体通常不出现在画面中；镜面自拍则可在镜中看见手机。后置镜头朝向当下活动，不能凭空出现 NPC 正脸。第一人称的手、鞋或衣角从人物自己的持机位置出现，不变成第三人称写真。同一时段的衣服、头发、妆容、背景和光线应与已知聊天连续。

“可爱”按人物习惯表现为真实微表情或生活细节，不是所有人统一嘟嘴、比心、磨皮。上游只说想念，不得自行升级成流泪、被抛弃或强烈委屈；任务明确且有情境支持“轻微委屈”时，可用短暂抿嘴、微皱眉或略带不服气的眼神，保留原有骨相，不制造哭红眼或病弱感。图片是虚构 NPC 场景，不伪称现实自拍证据。视频请求不是本照片任务的输出类型，不把一张静态图冒充视频。

## 摄影真实性

- 设备时代和成像水平来自 NPC 设定或任务，不默认所有人都用同一款旗舰手机。
- 主摄用于普通日常；超广角用于狭小空间、手臂长度自拍或强第一人称；远摄用于距离较远的抓拍。
- 私聊里随手发送的照片默认接近手机相册直出：中性色温、自然且不过浓的颜色、温和的明暗和局部锐化。除非任务明确要求，不加滤镜感、明显 HDR、浓艳花草、刻意提亮暗部或人像模式虚化。调用 `iphone-candid-photo` 时，其 ProRAW、Deep Fusion、Smart HDR 和 planned-candid 描述只作可选摄影参考，不覆盖这一默认观感。
- 人物随拍也按这个直出基线验收：白平衡和曝光可以有轻微手机自动调整，但皮肤不漂白、背景不蒙统一灰雾，局部阴影和正常对比仍在；不要为了显得“高级”加冷灰、奶油暖色、胶片颗粒或整张低对比预设。朋友圈精修另按用途处理，不能倒灌到私聊原图。
- 人物质感来自真实表面和光线，不靠后期叠噪点：在焦点和分辨率允许处保留适度毛孔、唇纹、肤色细微差异及衣料纹理；模糊处无需硬造清晰纹理。避免磨皮、蜡感与全脸均匀高光。
- 头发要有可信的生长方向、发根、发缝、分层和发梢；“柔顺”是发束顺着头型自然垂落，不是抹成一整块塑料。仅有少量符合动作和天气的碎发，避免无缘由的满头毛躁、纠缠、重复发丝或假发边缘。
- 只选二至四种符合场景的缺陷：轻微手抖、主体运动模糊、裁切不完整、前景遮挡、局部过曝、暗部噪点或白平衡漂移。
- 缺陷必须服务拍摄过程，不能把画面损坏到无法辨认主题。
- 禁止默认电影调色、摄影棚轮廓光、海报构图、专业相机虚化球和先超清后叠加颗粒的伪随拍。

## 私聊原图与朋友圈精修版

- 用途由上游指定。私聊随手分享通常保留接近直出的观感；朋友圈照片通常经过 NPC 自己挑选和手机修图，可按人物习惯调整裁切、曝光、色温、对比度与滤镜。修图程度要符合照片和人物，不把所有朋友圈套成同一套浓重预设。
- 如果 NPC 先把一张照片发给用户，后来决定把这张照片发朋友圈，朋友圈图必须以先前发送的原图为编辑目标。可以精修这张图，不能重新生成另一张拍摄视角、人物姿势或场景内容不同的照片来替代。
- 编辑时保持同一拍摄瞬间的主体、身份、动作、物件关系和环境。裁切与色调可以改变，不能凭修图增删人物、食物或宠物，或改变现实光线来源；脸、身体和食物材质仍须可信。
- 保存原图和精修版两个资产，并记录原图路径或 ID 到精修版的关联，方便私聊和朋友圈分别调用。

## 组图

- 每张单独生成，不烘焙轮播点、箭头或社交软件截图边框。
- 同组的脸、衣服、发型、天气、光线、餐桌和物件位置必须连续。
- 动作变化像相邻时刻，不在同组内突然换地点、换发型或换一套摄影灯。
