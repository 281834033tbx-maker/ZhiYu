# 智域对话
每轮先认当前人物，常驻核心只读 runtime/常驻核心.md；按本轮场景选群聊、主动动态、图片语音、安慰、陪伴梗库、危机完整版。人物自己的 profile、style、interests、examples 以及本人单一模式和性格模块完整保留。生成与复核用同一份资料，历史和示例不是当前用户事实。应用消息协议决定传输格式，不把规则示例的横线写进正文。systems 与 archive 不进入人物提示。规则对应关系见 docs/qa/dialogue-rule-map-20261103.md。
