# 实时知识与兴趣圈（给开发）

## 一、三类知识
| 知识 | 内容 | 位置 |
|---|---|---|
| 专业知识库 | 对不对、怎么做 | npcs/<id>/knowledge/ |
| 公共常识库 | 是什么、最近发生了什么（事件卡、未来事件日历） | world/ |
| 兴趣圈知识包 | 圈子里怎么说话、吐槽什么、什么梗、在吵什么 | world/circles/<圈子>.md |

## 二、兴趣圈知识包
- 每个游戏、运动、剧、明星单独一个圈子。
- 分三层：深（智友本人爱好，完整知识包）、中（大众热门圈子，先做150个以上，精简知识包）、浅（不预先做，用户聊到联网现查）。
- 结构：黑话 / 梗和名场面（标档次）/ 圈子情绪 / 常见情境怎么接 / 时下动态 / 敏感内容（单列，标已确认或未证实）。
- 程序每月统计用户最常聊、还没有知识包的圈子，补进“中”层。
- 采集指令见项目文件《给Codex的兴趣圈采集指令》。

## 三、实时知识（按变化快慢，全部自动）
| 层 | 内容 | 更新 | 人工 |
|---|---|---|---|
| 圈子底子 | 黑话、老梗、圈子情绪 | 每月自动重采，出“新增 / 停用”清单 | 深层圈子看清单 |
| 热点 | 比赛结果、新版本、明星八卦、刷屏的事 | 每隔几小时抓热榜（微博、抖音、B站、虎扑、NGA、各圈子新闻），生成事件卡 | 只处理标成敏感的 |
| 长尾 | 用户随口提到的 | 用户聊到时现搜，生成事件卡 | 不用管 |

## 四、事件卡
| 字段 | 例（AL世界赛0胜出局） |
|---|---|
| 标题 | AL世界赛0胜出局 |
| 事实（每条至少两个来源） | LPL一号种子，瑞士轮0胜3负，小局0比4，输给KC、TES、TL |
| 时间 | 2026年10月 |
| 赛前预期 | 一号种子，被看好 |
| 意外程度 | 爆冷 |
| 情绪基调 | 崩溃、丢人 |
| 主流看法 | 骂教练BP最多；下路被打穿；道歉不买账 |
| 少数看法 | 道歉没找借口 |
| 热梗名句 | 管泽元：来了世界赛的版本就不会玩游戏了 |
| 被点名的选手 | 下路Hope、教练Bigwei |
| 未证实 | 网上猜测，单列 |
| 敏感标记 | 隐私、违法指控、政治、色情、未成年 |
| 所属圈子 | 英雄联盟 |
| 有效期 | 两周 |

- 程序只把事件卡放进圈子等级为“深”和“知道”的智友上下文；“知道”只给标题和主流看法；“不知道”不给，也不现搜。
- 同一件事只抓一次，所有用户共用。
- 用正规搜索接口；生成内容过平台内容安全审核。

## 五、未来事件日历
- 上映日期、赛程、开播、版本更新、开票时间；每条至少两个来源；日期变了就更新。
- 每天和用户兴趣标签匹配，触发提醒（见 core/11 第三部分）。
- 比赛结束后拿到结果，半小时内触发赛后消息。
