# 群聊玩法（给开发和运营）

目标：用户感觉身边有一支随叫随到的私人团队。
原则：每个玩法要有真实用处；有频率上限，用户可以关；奖励只用虚拟的东西（勋章、动态、专栏）。

## 一、已确定：周报
- **Molly在和用户的私聊里发**，不发在群里；用户有几个专业群就合并成一份。
- 每周日晚8点；开场：老大，本周周报整理好了（Molly口吻待训练）。
- 数据由程序从任务总览直接算，不让模型算：训练几次、按计划吃了几天、带饭/做饭几次、体重本周平均和上周比、腰围、身体感受（睡眠、精力、酸痛三档）、下周调整。
- 评语：每个给用户布置了任务的专业智友各写一句（本周情况 + 下周一个具体调整），用本人口吻，署名放在最后。陪伴型不写。
  - 陈年：本周训练少了两组，下周把这两组分到其他几天补上
- 点某条评语 → 跳到那个智友的私聊并引用这条评语（程序功能）。
- 记录：每天早上空腹称重；周日量腰围（Molly周六晚提醒一次）；两周一次对比照片（可选）；没记录照发，标“本周没记录”，负责的智友在评语里提一句；连续两周没记录，负责的智友私聊问一次。
- 冷淡中的智友评语只写一句跟数据有关的；静默中的本周不写。

示例：
```
Molly：老大，本周周报整理好了
【第3周周报】
伴郎冲刺 D-9
训练：3/4次（周三没练）
吃饭：按计划6/7天（周六火锅）
带饭：4/5天
体重：本周平均166.2斤，比上周少1.4斤
腰围：91cm，比上周少1cm
身体感受：睡眠一般，精力好
下周调整：训练换冲刺版；婚礼前取消随便吃那一顿；带饭换成焖饭
陈年：本周训练少了两组，下周把这两组分到其他几天补上
柳智敏：火锅那顿没耽误事，婚礼前别再来了
赵一帆：焖饭做得不错，下周换香菇鸡腿的
```

## 二、已训练过的玩法
- **外出救急**：用户发菜单照片 → 柳智敏一分钟内圈出三道能点的；超市没有某样食材 → 赵一帆给替换。
- **拍照点评**：发饭的照片 → 柳智敏打分加改法，赵一帆补做法，不重复；发动作视频 → 陈年指出最该改的一处。
- **里程碑庆祝**：连续打卡7天/30天、减掉第一个5斤等 → Molly发里程碑，陪伴型被拉进群祝贺（庆祝时可以多人说话，每人一两句）；小满写一篇用户专栏发在她的动态（先问用户同意，不写具体体重）；何嘉伟一句话颁“月度之星”。庆祝结束陪伴型自动退群。
