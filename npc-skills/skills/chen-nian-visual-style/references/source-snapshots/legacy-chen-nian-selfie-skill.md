# 陈年自拍

把陈年的自拍视为已有视觉系统，不重新选脸或探索新审美。

## 固定资产

- `assets/chen-nian-face-reference.png`：唯一身份参考。身份相似度优先于姿势、造型和美化。
- `assets/front-leaning-selfie-style.png`：自拍构图、成像与气质参考。只锁定视觉语言，不把运动后出汗强加给冲突场景。

生成或修改图片前，同时使用这两张资产。其他用户图片只能作为动作、地点、服装或构图参考，不能改变陈年的脸。

## 自动触发

- 用户要求陈年“发自拍”“拍一张”“晒照片”“换头像”时，默认使用本技能。
- 用户要求陈年发朋友圈且画面包含陈年本人时，默认使用本技能。
- 用户只要求风景、食物、物品或其他人的照片时，不强行让陈年入镜。
- 用户明确要求替换固定自拍模板时才更新资产；普通换场景、换衣服、换表情不能改变模板。

## 永久视觉规则

1. **绝不小白脸**：保持成年男性的硬骨相——眉骨、颧骨平面、直而有力度的鼻骨、扎实下颌角和略长脸型。不得缩窄下颌、放大眼睛、提亮成奶油肌或抹掉真实不对称。
2. **克制硬汉感**：神态松弛、疲惫或直接，允许一点痞气；不用卖萌、噘嘴、无辜大眼、营业微笑或精致偶像姿态。硬朗不等于凶狠、暴力或过度成熟。
3. **近距离前倾**：默认胸口以上竖幅，身体略向镜子或镜头前倾，脸占画面较大比例；取景稍紧、略歪，像本人随手拍，不像摄影师棚拍。
4. **旧手机成像**：模拟 iPhone 6 时代的普通照片——轻微失焦、有限动态范围、暗部噪点、旧式降噪涂抹、轻度 JPEG 压缩、偶发运动模糊和不稳定白平衡。不得输出 HDR、锐利毛孔、商业人像或电影海报质感。
5. **不完美镜面**：默认镜面有薄雾、水点、指印、灰尘和不均匀擦拭痕，但五官仍可辨认。不得使用像新玻璃一样干净的镜子，也不能脏到遮住眼睛和身份特征。
6. **真实皮肤**：保留肤色差异、眼下疲态、小痣、淡印和自然毛孔；不磨皮、不塑料化、不追求左右完美对称。

## 默认场景与可变项

未指定场景时，使用固定参考中的运动后更衣室镜前自拍：湿发、汗珠、轻微泛红、宽松白色运动短袖、冷色荧光灯。

用户指定咖啡店、家中、车内、旅行或其他场景时，遵从场景，不凭空加入大汗淋漓；但仍保留硬骨相、克制神态、近距离前倾、旧手机低清与非精修质感。镜面不适用时，用脏玻璃、轻微镜头污迹或普通前置摄像头的柔糊感替代，不能升级成高清大片。

## 生成流程

1. 读取 `references/prompt-spec.md`。
2. 使用图像生成工具，每张独立成图单独调用一次。
3. 将身份资产标为唯一身份参考，将风格资产标为构图/成像参考；重复身份不变量和禁止项。
4. 检查身份、骨相、清晰度、镜面痕迹、场景合理性、手部和界面残留。失败项只做针对性重试。
5. 项目素材保存到 `public/npc/chen-nian/` 下，保留原图并使用版本化文件名。

朋友圈文案仍按陈年的角色语气和当前关系生成，不在图片中擅自加入文字、日期、定位、品牌标志或社交应用界面。
