# 2026-11-19 对话 Skill 与开场白同步

桌面端与手机版同步同一份73个现行对话规则文件，包含七人固定开场、人物资料和范例、当前输出检查、称呼偏好、自愿监督及必要安排运行接口。Molly第三项先使用公开品牌图片，明确标注“团队海报（临时示意）”；正式海报后续替换。新注册才有资格，旧账号和重新登录不补发，先说话会取消该人物尚未送达的开场。

桌面发布副本已通过冷 TypeScript、62项对话规范、40项执行回执、36组固定开场、21组七人真实中间件及9组开放注册检查。11份原生脚本语法与27项桌面身份/恢复/服务监督测试通过。隔离桌面开发服务另以真实回环HTTP验证7组注册、开场、空安排、称呼、重登与临时PNG资产。

共用应用与服务目录和已核手机版发布副本逐字相同；共用生产路径采用该副本的完整生产构建及原9组、新13组HTTP结果。桌面保留原公开Electron窗口与独立手机预览壳、可迁移持久身份；本轮没有重新安装/打包桌面App、在真实iPhone验收或重新跑真实模型考试。

全部新增运行验证只用临时账号/数据库，无外部模型调用，不带开发机账号数据、密钥或正式聊天。生产私有配置仍由使用者自行准备；同步源码不代表已部署公网服务。
