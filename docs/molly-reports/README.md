# Molly 今日简报与周报（2026-11-04）

## 2026-11-06 展示方式调整（现行）

每日简报与周报统一默认只显示顶部两行摘要，右侧只有一个展开箭头。点击抬头展开整张卡片，全部非空板块直接显示；各小板块不再有折叠按钮或箭头。再次点抬头可收起整卡。展开状态按账号、消息保存，忽略旧的分块折叠状态；新生成的卡片默认收起。仍采用200ms过渡，并支持键盘及减少动态效果设置。原采购、缴费、待定、引用与演示隔离保持。

## 查看与操作

登录后，Molly 私聊各生成一份演示简报与周报，开场分别为“早 两件事等你定”“周报 有两件要紧的”。按账号持久去重，刷新、多窗口、重新登录不会重复创建。

聊天列表右上角“+”→“简报与周报”：保存简报时间、城市、周报星期和时间；周报默认周日21:30。演示测试区可重新生成两类卡片，新卡片默认全部展开，旧卡片仍保留。时间与城市本期只保存，不改变固定样例，不触发定位、天气查询或真实定时发送。

- 简报依次展示待定、日程、采购、缴费、进度、近期、关注；周报依次展示要紧、身体、训练、饮食、做菜、护肤、账本、追踪、评语。空板块不显示。
- 两类卡片共享200ms折叠。状态按账号、消息、板块保存；按钮更新不重置折叠。
- 确认/暂不在原卡片更新；去选复用Molly选择气泡，只更新演示，不发送模型请求。固定样例未包含原腿训行，确认挪到明天后明确提示“腿部训练已挪到明天”，不编造明日训练时间、不把明晚列进本日范围。晚餐确认会在演示日程显示改期行。
- 采购清单为玻璃弹窗，按12类固定顺序显示、可复制/勾选，全部买齐后该单消失。复制格式经纯函数测试，实际界面可显示“已复制”。
- 缴费五类按钮只改变演示已缴状态，可点击撤回，不跳真实缴费渠道。3天内到期采用原危险色。
- 日程行及六位智友评语可跳转原智友并带真实消息ID引用；点击不假冒用户发言。周报内容保持生成时快照，简报的后续缴费不改旧周报。

## 数据与配置

共享数据模型：`lib/npc/molly-reports.ts`；固定样例在`lib/npc/report-config/daily-demo.json`、`weekly-demo.json`。全部模板、说明、费用/提醒配置、步骤、日期格式、近期规则、周报项目/板块/抬头库均在同目录，扩展专业板块由配置决定顺序。开场句原样保存在`npc-skills/skills/zhiyu-dialogue/npcs/molly/brief-openers.json`及`report-openers.json`。本期不开启每日/每周自动选句或防重复定时逻辑。

服务端演示操作独立于真实任务和支付；账号校验、来源校验、事务和忙碌保护沿用原架构。演示卡、开场、选择和投影引用均带`report-demo:`标识，模型历史、人物记忆、任务记忆、任务计划、实时通话和朋友圈事实输入均排除样例；用户显式引用时只作为标明的演示问题上下文。

## 验证

- TypeScript、全项目lint、颜色/字号/圆角检查、用户文案检查、生产构建。
- 演示领域回归：完整固定数据、同账号幂等、其他账号隔离、确认/暂不/选择、缴费撤回、采购完成、午夜排序、六位智友及Molly引用、周报不可变、不调用天气/模型。
- 演示历史隔离回归：七人模型上下文、六人记忆落库、真实健康记录保留、演示讨论不入任务/记忆、伪造普通选择请求被拒。
- 原秘书委托、体验/历史报告展示、任务记忆与任务澄清回归。
- 正常浏览器对独立临时账号实测折叠持久、待定/缴费、采购复制与勾齐消失、评语引用、去选、次日06:00排最后并标明天、设置保存和重新生成、两主题显示。预览不读取正式API或账号，不调用模型、天气或支付。

UI复现：先用纯UI的Vite配置提供资源，再以`ZHIYU_FIXTURE_ASSET_PORT=<资源端口> node scripts/molly-reports-ui-fixture.mjs`启动临时演示。`/fixture/edge-cases`是显式QA变体，用于去选与午夜行，**不属于正式固定样例**。测试退出会删除临时数据库。
