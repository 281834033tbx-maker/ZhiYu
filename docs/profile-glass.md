# 桌面资料、导航与报告界面（2026-11-06）

桌面导航左下角使用无背景三横菜单，点击直接打开玻璃设置窗口，不再进入单独的“我”页面。设置窗口与人物资料卡、私聊及群聊侧栏采用协调的冷灰绿、浅紫玻璃底色；各渐变层的透明度、停点、24px模糊及125%饱和度保留。移除浮层白色边框与白色内高光，保留原阴影。系统减少透明度及不支持模糊时的备用样式保持，本人照片式资料卡继续使用独立照片材质。

会话列表不再显示人物状态；聊天头部的姓名下方及资料状态使用有边框、淡色底的小胶囊。人物资料和聊天侧栏的正文采用统一聊天字号，并跟随字号设置；状态文字再小一号。个性签名恢复为标签在左、正文在右的单行布局，按可用宽度自动省略，悬停可查看完整文字。备注输入与悬停框收紧至28px，使用柔和透明混色，避免突兀的纯白底。专业背景、证书、动态圈、来源、备注编辑及消息/视频入口保留。

各导航内容区共用聊天背景变量：浅色为纯白，深色与深色聊天一致。当前联系人、动态及任务内容区适用同一规则，新增导航内容区也继承这一基底。板块一保留原4%灰青底色与macOS原生磨砂，停用原生窗口上额外叠加的CSS液态透镜及白色边缘高光，网页环境保留回退材质。

每日简报与周报复用普通聊天气泡的颜色、内距和圆角。折叠时只显示“今日简报”或“本周汇报”与“展开”；点击后整卡展开，按钮改为“收起”。城市、天气和限行位于今日简报展开后的首块，待定事项随后显示；周报日期及摘要保留在展开内容中的本周概览。内部小板块直接显示，不单独折叠。原操作、展开偏好持久化及账号隔离保留。

本轮替代早期姓名旁列表状态、全宽签名及日期天气摘要折叠卡的呈现方式。启动品牌加载页和既有业务功能保留；源码不附真实账号、聊天记录、本机运行配置或截图。

## 同日增量：字号与训练动作要点

人物资料和聊天侧栏正文统一为13px，状态标签和状态值为12px，两者继续跟随字号设置。训练任务名称只保留动作名称，动作要点放入展开后的正文；展示时会分离明确标记的旧标题要点，并保留原步骤提示和说明，不重写原任务记录或完成进度。未来日期的训练也可以只读查看要点，完成与计时仍受原计划日期约束。
