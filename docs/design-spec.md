# 智域界面设计规范

生效：2026-11-03。现有主题颜色、渐变和透明度值冻结；此规范不授权新配色。后续界面修改必须先运行 `npm run lint:style` 与 `node scripts/test-user-facing-copy.mjs`。

## 2. 字号与字重

### 2.1 字号：7 档

全部写成 `calc(档位 + var(--zy-font-adjust,0px))`，保证设置里的“小 / 标准 / 大”照常生效。

| 档位 | 用在 |
|---|---|
| 28px | 周报、月报、早报里的大数字 |
| 20px | 页面标题、资料卡里的人名 |
| 16px | 聊天顶部名字、弹窗标题、抽屉标题、卡片标题 |
| 14px | 弹窗和抽屉里的项目名、内容、按钮文字 |
| 13px | 聊天气泡正文、会话列表名字（保持现在的 13，不改） |
| 12px | 会话摘要、状态、说明文字、账号、地区 |
| 11px | 时间、未读数、角标（最小，不再有 9px、10px） |

现有的其他字号就近归档：9、10 → 11；12.5 → 12；15 → 14；17、18 → 16；22、24 → 20。

### 2.2 字重：只留 400 和 600

所有 470、480、500、520、530、540、550、560、570、580、620、650、700 都改成 400 或 600：
- ≥ 550 的改成 600；
- < 550 的改成 400。

原因：苹方和微软雅黑没有这些中间粗细，Mac 和 Windows 上显示得不一样。

## 3. 圆角与阴影

### 3.1 圆角：4 档，另有不动的

| 档位 | 用在 | 合并现有的 |
|---|---|---|
| 6px | 角标、标签、菜单选项的悬停底、小图标按钮 | 2、3、4、5、7 |
| 10px | 输入框、搜索框、按钮、右键菜单选项、缩略图 | 8、9、11 |
| 12px | 板块、弹窗、抽屉、设置窗、任务卡、资料卡、早报 / 周报 / 月报卡片 | 13、14、16、18、20、22、24、26、32 |
| 50% / 999px | 头像、未读数、开关、胶囊按钮 | 不变 |

**不动的**：聊天气泡（21px + 连发小角 5px）、聊天里的图片、板块 2 和板块 3 交界处的直线和 12px 圆角。

**桌面人物的小对话框**（`.zy-character-bubble`，现在是 `12px 12px 3px 12px`）：改成和对方聊天气泡同一个形状，单条消息时用 `21px 21px 21px 5px`，内边距、字号和聊天气泡一致。它的底色不改。

### 3.2 阴影：默认不加，只留 3 种

| 名称 | 值 | 用在 |
|---|---|---|
| 板块分界 | 现有 `--zy-layer-shadow` | 只用在板块 2 左边缘 |
| 浮层 | 现有 `--zy-popup-shadow` + 玻璃的内高光 | 弹窗、抽屉、右键菜单、下拉菜单、资料浮窗 |
| 输入框轻影 | 现有 `--zy-composer-shadow` | 只用在聊天输入框 |

其余所有地方去掉阴影，包括列表、卡片、按钮、气泡、早报 / 周报 / 月报卡片。

## 4. 弹窗统一：透明玻璃 + 头发丝分割线

参考现在的智友资料卡（头像点开的那张）。它已经是对的方向，所有弹窗都按它统一。

### 4.1 哪些算弹窗

`theme-glass.css` 里已经列出的全部（设置、退出、宠物、副本、各种菜单、右键菜单、表情面板、动态通知、@ 菜单、任务选择、私聊设置抽屉、群设置抽屉、toast、图片查看器的菜单和转发），再加上：
- 发起群聊、转发消息（`group-create-dialog`、`message-forward-dialog`）
- 早报设置（`morning-reminder-settings`）、实时语音设置（`realtime-speech-settings`）
- 专业任务详情（`professional-task` 的弹窗）、今日任务弹窗
- 个人资料卡（`self-profile-card`）

逐个检查上面每个弹窗，都要用同一种材质：`background: var(--zy-glass-fill)`，边框 `var(--zy-glass-border)`，`backdrop-filter: blur(24px) saturate(125%)`，阴影用 3.2 的“浮层”。弹窗自己写死的底色（`#fafafa`、`#fafaf8`、`#fff` 等）全部去掉，改用玻璃。模态弹窗后面的遮罩沿用现有的 `--zy-glass-backdrop` + `blur(5px)`。

### 4.2 分割线：头发丝

- 线宽 0.5px，颜色 `var(--zy-glass-line)`。不用黑色，不用 `#eff0ed`、`#f0f0f2`、`#e3e5dd` 这类写死的灰。
- **左右留白**：弹窗和资料卡左右各留 24px，右侧抽屉左右各留 20px。线不能从边拉到边。
- 普通屏（`devicePixelRatio < 2`）上 0.5px 可能不显示：用 `1px` 线加 `transform: scaleY(.5)`，或用 `1px` + `var(--zy-glass-line)`，二选一，保证两种屏幕都看得到、都很细。
- **只在分组之间画线。** 同一组里的行和行之间不画。例如资料卡：头部 | 备注、状态、个性签名 | 动态圈 | 添加来源 | 底部操作，每两组之间一条线。
- 确认弹窗（清空、删除、退出）的底部按钮：上方一条通栏的头发丝线（这里允许从边到边），两个按钮中间一条竖的头发丝线，按钮高 48px。

### 4.3 文字层级：所有弹窗只用这 6 种

| 层级 | 字号 / 字重 | 颜色（已有变量） | 用在 |
|---|---|---|---|
| 大标题 | 20 / 600 | `--zy-ink` | 资料卡里的人名 |
| 标题 | 16 / 600 | `--zy-ink` | 弹窗标题、抽屉标题、确认弹窗的问题 |
| 正文 | 14 / 400 | `--zy-ink` | 左边的项目名（备注、状态、个性签名、动态圈、添加来源）、右边的内容、按钮文字、开关名 |
| 辅助 | 13 或 12 / 400 | `--zy-glass-muted` | 账号、地区、添加来源的值、说明文字、版本号、右侧箭头前的当前值（“07:00”“深圳”） |
| 操作 | 12 / 600 | `--zy-nav-active` | 资料卡底部的“发消息”“视频”等图标按钮 |
| 危险 | 14 / 400（确认弹窗里 600） | `--zy-glass-accent-ink` | 只用于删除、清空、退出登录确认 |

- 加粗只给大标题、标题、操作三种，其他一律不加粗。
- 群设置抽屉里写死的 `--zy-group-detail-title:#000` 和 `--zy-group-detail-value:#9d9da4` 去掉，分别改用“正文”和“辅助”。设置窗口里的 `#171719`、`#000`、`#8b8b93`、`#727278` 同理。
- 资料卡里“备注”的值、“个性签名”的值是“正文”（黑色）；“添加来源”的值是“辅助”（灰色）。

### 4.4 间距

- 弹窗内边距：左右 24px，标题区上 20px、下 16px；每组上下各 14px。
- 抽屉内边距：左右 20px。
- 列表行（发起群聊、转发）：高 54px，头像 36px，勾选圆 20px。
- 弹窗里的输入框、搜索框、分段选择器：底 `var(--zy-glass-inner)`，边 `var(--zy-glass-line)`，圆角 10px，高 34px。
- 主按钮（完成、确定）沿用现有深色按钮的颜色，次按钮用 `var(--zy-glass-inner)` 底 + `var(--zy-glass-line)` 边，都是高 34px、圆角 10px。

## 5. 状态

### 5.1 规则

- 每个智友有一个状态库，状态由程序按当天生活脚本自动更换，用户不能改，也**不能点开**，只显示。
- 数量：陪伴智友（夏夏、徐小曼、何嘉伟）每人约 20 条，专业智友（陈年、柳智敏、赵一帆）每人约 12 条，Molly 4 条（在线、整理周报中、排明天的日程、盯进度）。
- 每人每天换 3–5 次，同一小时内不换两次，每条最多挂 24 小时。
- 智域事件（`智域事件与八卦系统`）可以临时换上事件状态，比如陈年“写检讨中”，挂 1–2 天，期间优先显示。
- 生气静默期间，显示“暂时不想说话”，静默结束恢复原状态。
- 状态文字 2–8 个字，不带表情，不带句号。
- **不准出现**：表示没空或不在的状态（睡觉中、忙、勿扰、晚点回、离线），因为智友永远秒回；说自己在真实地方、玩真实游戏的状态（“在打排位”“在迪士尼”）；Molly 的生活类状态。

### 5.2 状态库文件

放在 `npc-skills/skills/zhiyu-dialogue/npcs/<id>/status.json`，Molly 放在 `npcs/molly/status.json`：

```json
{ "items": [ { "text": "在追番", "slots": ["evening", "night"], "weight": 2 } ] }
```

`slots` 取值 `morning / noon / afternoon / evening / night`，用来和生活脚本的时段对应。按下面的示例和人设补满到上面的数量，交付时单独列出全部状态，等用户审阅：

| 智友 | 示例 |
|---|---|
| 夏夏 | 在追番、准备今晚直播、救助站撸猫、恐怖片看到一半不敢看了、抓娃娃又失败了 |
| 徐小曼 | 写稿中、卡文了、在看吃播、读一本悬疑、交稿了，放空 |
| 何嘉伟 | 晨跑、在看季度数据、面试新人、复盘中 |
| 陈年 | 带课中、练腿日、下午打球、研究新动作 |
| 柳智敏 | 改食谱中、周三螺蛳粉日、看文献、备周菜单 |
| 赵一帆 | 逛菜市场、熬汤中、给同事做午饭、试新菜 |

### 5.3 显示位置

1. **聊天顶部名字下面**：现在显示的是个性签名（`chat-header.tsx` 的 `bio`），改成显示状态。Molly 现在显示的“您的智能机器人助手（闲聊200）”也换成她的状态。正在输入时，这一行临时变成“正在输入…”（见第 11 节）。
2. **会话列表摘要前面**：`状态 · 最后一条消息`，例如“带课中 · 腿练了没”。
3. **资料卡**：在“备注”和“个性签名”中间加一行“状态”，样式和其他行一样（左“正文”项目名，右“正文”内容）。
4. 个性签名本身保留，只在资料卡里显示。
