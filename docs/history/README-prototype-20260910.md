# 智域 · 桌面交互设计工作台

依据 2026-09-10 桌面版 PRD 实现的浏览器交互原型。固定桌面三栏布局，非原生安装包；无真实 AI 服务、支付或多用户后端。

## 使用

- 画布空白处拖动；滚轮缩放；页面内滚轮滚动内容，Ctrl/Command + 滚轮缩放画布。
- 拖动标题栏移动页面；双击标题栏或点击播放进入单页体验。
- 左侧添加页面/备注；标题栏复制、移除、编辑；底部撤销或 Command/Ctrl + Z 撤销页面操作。
- 右侧编辑器修改页面名称、说明，以及跨页面同步的角色名称、身份、简介。
- 演示数据与画布自动保存于当前浏览器 localStorage。可导出 JSON、追加导入页面或恢复完整备份。完整恢复前自动导出当前版本。
- 头像、聊天图片、朋友圈附件采用本机数据预览，每个文件限 2MB。浏览器存储不足时会明确提示导出备份。
- 联系人解锁仅模拟，不产生扣费；NPC 回复采用预设文案；用户 ID 可用性为本机模拟。游戏与通讯录分组按 PRD 保留占位。

## 设计

深绿导航、清爽灰白内容面与低饱和绿色消息气泡。保留微信式紧凑搜索和三栏骨架，增加可选晚安模式。初始画布包含聊天、联系人、朋友圈、个人设置和游戏五个页面。

## 验证记录

通过 TypeScript 检查、生产构建与页面 HTTP 响应检查。未执行浏览器点击/视觉测试。WebMCP 备注工具支持检测后注册；当前环境无对应验证上下文，未验证浏览器内注册执行合同。
