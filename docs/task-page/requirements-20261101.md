## 1. 整体布局

任务页改成三栏，和现有「多功能区」页面同一套外壳（左侧主导航 + 中间指引栏 + 右侧内容区），直接复用多功能区的主导航和指引栏容器。

| 区域 | 宽度 | 背景 |
|---|---|---|
| 主导航 | 72px，固定 | 沿用现有（`#D7DEE6 → #C9D2DC` 竖向渐变） |
| 指引栏 | 272px，固定 | 沿用多功能区：`linear-gradient(165deg, #B4D1CC 0%, #CBD2D8 48%, #CEC7DF 100%)` |
| 内容区 | 剩余宽度 | `#FFFFFF` |

- 内容区内边距 `30px 44px 48px`，里面的内容最大宽 760px，水平居中。
- 主导航里「任务」图标为选中态（白色半透明底 `rgba(255,255,255,.6)`，圆角 12px）。
- 指引栏和内容区各自独立滚动。

## 3. 公共组件

### 3.1 任务行（TaskRow）

所有页面（今天、未来、历史）的任务都用同一个任务行，见 `06-任务行规范.png`。

```
[状态圆圈]  任务名 [步数徽章]                    [进度胶囊] [展开箭头]
            [头像] 分量 · 提醒
```

- 行内边距 `13px 0`，元素间距 12px，底部 1px 分隔线 `#EEEEEC`。
- 行上不放任何按钮。所有操作都在展开后的底部。
- 不显示时间，也不按上午、下午分组。
- 第二行固定写「分量 · 提醒」两段：
  - 分量：要多久或多少，如「25 分钟」「乳清 30g」「1 勺」「每次 250ml」。
  - 提醒：最需要记住的一句，不超过 12 个字，如「练完 30 分钟内」。
  - 没有提醒就只写分量。不要写智友名字、计划名、功能标签。
  - 必须准点的事，时间写进这一行，如「23:00 前 · 明早 7:00 起」。
- 展开箭头：30×30 按钮，图标 18px，`#8E8E93`。收起时箭头朝下，展开后朝上。
- 点击整行（除圆圈外）也可以展开或收起。

### 3.2 状态圆圈

22px 圆，描边 1.5px `#B8B8BE`，白底。

| 状态 | 样式 | 点击 |
|---|---|---|
| 未完成 | 空心 | 见 9.1 |
| 已完成（今天页「已完成」区） | `#C7C7CC` 实心 + 白色对勾 | 取消完成，回到待完成 |
| 未来的任务 | 描边 `#D1D1D6`，不可点 | 无 |
| 历史：已完成 | `#E5787C` 实心 + 白色对勾 | 改为没做到（补记） |
| 历史：没做到 | 空心，描边 `#C7C7CC` | 补记为已完成 |

### 3.3 步数徽章

- 任务有步骤、且一步都还没做时，显示在任务名后面：灰色小圆角块，里面一个数字。
- 尺寸：高 18px，最小宽 18px，圆角 9px，底 `#ECECEA`，字 11px / 600，`#3F444C`。
- 数字就是步骤数；采购任务是物品数。
- 一旦做了至少一步，徽章消失，换成右侧的进度胶囊。

### 3.4 进度胶囊

样式见参考图（白色胶囊）：

- 高 30px，圆角 15px，左右内边距 `0 13px 0 11px`，白底。
- 描边用 `box-shadow: inset 0 0 0 1px #E8E8E6, 0 1px 2px rgba(0,0,0,.04)`。
- 文字 13px / 600。

| 状态 | 左侧图形 | 文字 |
|---|---|---|
| 没做完 | 14px 进度环（底环 `#E6E6E4`，进度用分类色；今天页头部用 `#D93A40`），按进度比例填充，进度变化时有动画 | `3 / 5 完成` |
| 全部做完 | 7px 绿点 `#2F8F5B` | `5 / 5 完成` |
| 计数型 | 进度环 | `1000 / 2000ml`（不加「完成」两字） |

出现位置：

1. 今天页右上角：今天已完成数 / 今天总数。
2. 进行中卡片头部：当前任务的步骤进度。
3. 待完成列表里做了一部分的任务（例如做了一半被换下来）。
4. 计数型任务已有进度时。
5. 历史页每天的标题右侧：当天完成数 / 当天总数。

### 3.5 按钮

| 类型 | 样式 |
|---|---|
| 红色主按钮 | 底 `#D93A40`，白字 |
| 黑色按钮 | 底 `#1C1C1E`，白字 |
| 白色按钮 | 白底，描边 `inset 0 0 0 1px #E2E2E0`，黑字 |

统一尺寸：高 36px，左右内边距 16px，圆角 10px，13.5px / 500。按钮里的图标 16px，和文字间距 6px。

### 3.6 展开区与底部按钮规则

- 任务展开后，下面出现一个区域：左边缩进 34px（和任务名对齐），内边距 14px，圆角 16px，底色 `#F7F7F5`。
- 区域里先是内容（步骤列表或说明文字），最下面一行是按钮。
- 底部按钮规则（见 `02-任务展开后.png`）：

| 场景 | 左边 | 右边（从左到右） |
|---|---|---|
| 今天 · 步骤型 · 还没开始 | 与智友对话（红） | {动词}完成（白）、开始{动词}（黑） |
| 今天 · 步骤型 · 做了一部分被换下来 | 与智友对话（红） | {动词}完成（白）、继续{动词}（黑） |
| 今天 · 步骤型 · 正在进行中 | 与智友对话（红） | {动词}完成（白） |
| 今天 · 单次型 | 与智友对话（红） | 完成（白） |
| 今天 · 计数型（喝水） | 与智友对话（红） | 喝完了（白）、记一次 250ml（黑） |
| 未来 | 与智友对话（红） | 灰色文字「明天才能开始」，明天以后写「11月3日才能开始」，没有任何开始或完成按钮 |
| 历史 | 与智友对话（红） | 无 |
| 进行中 · 已经结束 | 与智友对话（红） | 灰色文字「已完成」或「已结束」 |

- {动词}来自分类配置（训练 / 做饭 / 采购 / 拉伸 / 护肤），例如「开始训练」「训练完成」「开始做饭」「做饭完成」。
- 「记一次 ××ml」里的毫升数来自任务的每次量（`perTime`）。
- 「与智友对话」按钮前面放麦克风图标，文字固定写「与智友对话」，不写具体智友名字。
  - 点击后打开和这个任务所属智友（`npcId`）的对话，并把当前任务作为上下文带进去（语音和文字都在这个对话里）。

### 3.7 步骤行（展开后的竖向步骤）

见 `02-任务展开后.png` 第 1、2、3 张。

- 高 48px，圆角 12px，白底，描边 `inset 0 0 0 1px #ECECEA`，左右内边距 `0 8px 0 14px`，步骤之间间距 7px。
- 每行从左到右：完成圆圈（22px，可点击勾选这一步）、步骤名（14.5px / 500）、休息或时长小胶囊、展开箭头。
- 不要「动作要点」「查看图片」这类文字链接。
- 小胶囊：12px 字，`4px 10px` 内边距，圆角 14px，描边 `#E3E3E1`，`#6E6E73`。内容如「休息 1分30秒」「10分钟」。
- 已完成的步骤：圆圈 `#E5787C` 实心 + 对勾，名字划掉，颜色 `#8E8E93`。
- 当前步骤（进行中）：
  - 整行描边 1.5px `#F0C7A3`，名字加粗；
  - 小胶囊换成高亮样式：底 `#FDE7D3`，字 `#7A3A0C` / 600，内容「休息中 01:29」，实时倒计时。
- 点某一步的箭头，展开这一步的详情（同一时间只展开一步）：
  - 组数标签：每组一个小块，已完成「第1组 ✓」（`#E8853A` 底白字），当前组（`#FDE7D3` 底 `#7A3A0C` 字），未做组（`#F0F0EE` 底）。后面跟「4 × 8 · 50kg」。
  - 要点：圆点列表，13.5px，行高 1.75。
  - 动作图：右侧 112×84 圆角 10px，没有图时放灰色占位。
  - 做饭类步骤的详情另外有「开始 3 分钟计时」按钮，见 `07-三级展开.png`。
- 未来页的步骤只读：左边是序号圆（20px，底 `#F0F0EE`），右边是组数或时长，不能勾选，不能展开。

### 3.8 确认弹窗

见 `03-结束任务与进行中状态.png` 第 1 张。

- 遮罩：`rgba(28,28,30,.32)`。

## 5. 今天页

见 `01-今天.png`。从上到下：

### 5.1 头部

- 左边：「今天」（30px / 700），下面一行日期「11月1日 周日」。
- 右边：进度胶囊「3 / 12 完成」，和标题底部对齐。
- 不要「还剩 N 项」。

### 5.2 进行中

规则：

1. 同一时间最多只有一个任务在进行中。
2. 平时这一块不存在，只有用户在某个任务上点了「开始{动词}」才出现。
3. 只有步骤型任务能开始，单次型和计数型不会进入进行中。
4. 开始另一个任务时，原来的进行中任务被换下来：
   - 如果没做完，它回到「待完成」列表原来的位置，右侧显示进度胶囊（如「3 / 5 完成」），按钮变成「继续{动词}」；
   - 如果已经结束，它进入「已完成」列表。
5. 进行中的任务结束后（见 9.3），这一块不消失、不变灰，原样留着，只是变成完成状态，直到用户开始下一个任务才被替换。
6. 正在进行中的任务不在下面的「待完成」「已完成」列表里重复出现。

结构：

- 区块标题：橙色圆点（7px，`#E8853A`）+「进行中」（13px / 600，`#9A4A0B`），上间距 24px。
- 卡片：底 `#F6F5F2`，圆角 18px，内边距 `18px 18px 16px`，和标题间距 8px。

**卡片头部：**

```
[分类图标 40px]  胸部训练                   [进度胶囊 2 / 5 完成] [箭头]
                 [头像] 50 分钟 · 第三组可以降重
```

所有分类的任务都只归为这三种。见 `06-任务行规范.png`。

## 9. 交互与状态流转

### 9.1 点击未完成任务的圆圈

| 类型 | 行为 |
|---|---|
| 步骤型 | 弹确认框「结束{任务名}？」→ 选「是」后任务完成，移入「已完成」 |
| 单次型 | 直接完成，移入「已完成」 |
| 计数型 | 当前量 + 每次量；达到目标后自动完成，移入「已完成」 |

### 9.2 开始任务

点「开始{动词}」或「继续{动词}」：

1. 如果进行中已有一个没结束的任务，它退回待完成，保留进度，按钮变「继续{动词}」。
2. 如果进行中已有一个已结束的任务，它进入已完成。
3. 当前任务进入进行中区块，默认收起（横向步骤条），从第一个没做的步骤开始。
4. 页面滚到顶部，让用户看到进行中卡片。

### 9.3 结束进行中的任务

点「{动词}完成」→ 确认弹窗：

- 选「否」：关闭弹窗，什么都不改。
- 选「是」：
  - 任务状态变成完成（全部步骤做完）或已结束（有步骤没做，记录实际完成数）；
  - 卡片原样留在进行中，按 5.2「结束后的样子」显示；
  - 头部胶囊 +1。

### 9.4 步骤进度

- 勾选一个步骤的最后一组后，这个步骤完成，自动跳到下一步，开始这一步的休息倒计时。
- 休息倒计时显示在当前步骤的小胶囊和横向步骤条的详情里，每秒刷新。
- 所有步骤都勾完后，不自动结束，等用户点「{动词}完成」。

### 9.5 进度胶囊动画

数字变化时，进度环从旧比例平滑过渡到新比例（300ms ease-out）。变成全部完成时，环淡出，换成绿点。

### 9.6 置顶

任务行右键菜单：「置顶 / 取消置顶」。同时可以有多个置顶，置顶之间按 `order` 排。

## 10. 数据模型

```ts
type TaskType = 'steps' | 'single' | 'count';
type TaskStatus = 'todo' | 'in_progress' | 'paused' | 'done' | 'ended' | 'missed';
// paused = 开始过但被别的任务换下来；ended = 提前结束；missed = 历史里没做到

interface CategoryGroup { id: string; name: string; order: number }   // 运动 / 饮食 / 生活 / 形象管理
interface Category {
  id: string; name: string; groupId: string;
  color: string; icon: string;
  verb?: string;        // 训练 / 做饭 / 采购 / 拉伸 / 护肤，用于按钮文字
}

interface Npc { id: string; name: string; avatar: string }

interface Plan {
  id: string; name: string; color: string;
  progress: number;       // 0–1，进度条
  progressText: string;   // 「第 4/12 周」
}

interface Step {
  id: string; name: string;
  detail: string;          // 「4 × 10」「10分钟」，未来页和收起步骤条显示
  restSeconds?: number;    // 组间休息，小胶囊「休息 1分30秒」
  durationText?: string;   // 做饭类的小胶囊「10分钟」
  sets?: { total: number; done: number; weight?: string };
  tips?: string[];         // 要点
  image?: string;          // 动作图 / 步骤图
  timerSeconds?: number;   // 做饭步骤的计时
  done: boolean;
  skipped?: boolean;
  actual?: string;         // 历史：实际完成情况「4 × 10 · 42.5kg」
}

interface Task {
  id: string;
  title: string;
  categoryId: string;
  npcId: string;
  type: TaskType;
  amount: string;          // 分量
  tip?: string;            // 提醒，≤12 字
  date: string;            // YYYY-MM-DD
  repeat?: 'daily';
  order: number;           // 建议顺序
  pinned?: boolean;
  status: TaskStatus;
  steps?: Step[];
  count?: { current: number; target: number; perTime: number; unit: 'ml' | '步' | '次' };
  note?: string;           // 单次型展开后的说明文字
  missReason?: string;     // 「太累了」「在外面吃」
  missText?: string;       // 计数型没达标时的「喝了 1500ml」
  completedAt?: string;
  planId?: string;
}

interface TaskPageState {
  view: 'today' | 'future' | 'history';
  futureRange: 7 | 30;
  historyFilter: 'all' | 'done' | 'missed';
  categoryFilter?: string;
  activeTaskId?: string;          // 进行中的任务，只有一个
  activeExpanded: boolean;        // 进行中卡片是否展开
  expandedTaskIds: string[];      // 列表里展开的任务
  expandedStepId?: string;        // 展开详情的那一步（全局最多一个）
  weeklyReview: { time: string }; // 「今晚 21:00」
}
```

## 12. 不要做的

- 不要顶部「总任务 / 已完成 / 待完成」三张大卡片，不要大号「0%」。
- 不要横排的分类图标栏（旧版的「总体 / 做饭 / 健身…」）。
- 任务行上不放任何按钮（「+1 杯」「开始」「交给 Molly」都不要）。
- 不显示任务时间列，不按上午、中午、下午、晚上分组。
- 不要「待你决定」入口，列表里也不放 A/B 选择题。
- 不要「全部 N 个」「还有 N 项」「已完成 N 项 ›」这类折叠入口（未来页 30 天以外的天数除外）。
- 分类不能折叠，不要「编辑」。
- 计划名后面不放头像。
- 本周复盘卡片不可点击，不要右侧箭头。
- 进行中同时只能有一个任务；结束后不要变灰，也不要让这一块消失。
- 不要「今天都做完了」的庆祝页面。
- 按钮上不写具体智友名字，统一写「与智友对话」。
- 步骤上不要「动作要点」「查看图片」文字链接。
- 喝水不用「杯」，统一用毫升。
