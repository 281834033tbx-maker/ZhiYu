## 4. 字幕

### 4.1 位置

- 水平居中，底边距窗口底部 150px（在按钮上方）。
- 区域宽 760px，高 96px，内容贴底排列（`flex-direction: column; justify-content: flex-end`），行间距 6px，文字居中。
- 最多显示 2 行：上一句 + 当前句。

### 4.2 样式

字幕全部不加粗，不用纯白。两个人的字幕只用字号和亮度区分，不写「我」「小曼」这样的名字前缀。

| 谁说的 | 字号 / 字重 | 颜色 | 行高 | 阴影 |
|---|---|---|---|---|
| 人物（当前句） | 18px / 400 | `rgba(246,240,234,.9)`（暖白） | 28px | `0 1px 10px rgba(0,0,0,.45)` |
| 用户（当前句） | 15px / 400 | `rgba(255,255,255,.62)` | 28px | `0 1px 10px rgba(0,0,0,.45)` |
| 上一句（不管谁说的） | 15px / 400 | `rgba(255,255,255,.62)` | 22px | `0 1px 8px rgba(0,0,0,.4)` |

- 被打断的那句后面不加「· 已打断」，直接停在打断的位置。
- 一句太长时最多 2 行，超出部分只显示最后 2 行（新字在下面，旧字往上推出去）。

### 4.3 文字怎么出来

- **人物的话**：跟着语音一个字一个字出来。用服务端 `transcript`（role = assistant）的流式结果，同一个 `turnId` 原地替换整句，不要追加。
- **用户的话**：用 ASR 的流式结果，同一句原地替换。只有 `final: true` 时才算这一句结束。
  - 严禁把每次的中间结果拼接到后面（旧版有这个 bug，同一句话会重复好几遍）。
- **人物还没开口时**（状态是 `thinking`，或者是 `speaking` 但还没有文字）：当前句位置显示三个呼吸点。
  - 点 5px 圆，颜色用人物字幕色，间距 4px；
  - 透明度 .25 ↔ .9，1.2s 循环，三个点依次延迟 0 / .2s / .4s。
  - 第一个字出来后，点消失。

### 4.4 新字幕出现的动画

新的一句开始时（新的 `turnId`，或者换了说话人）：

1. **当前句变成上一句**：往上移到上一行，同时变成 15px、`rgba(255,255,255,.62)`。
   - 动画：`translateY(30px) → 0`，320ms，`cubic-bezier(.2,.8,.2,1)`。
2. **原来的上一句**：直接移除，不做动画。
3. **新的一句出现在当前句位置**：`opacity 0, translateY(12px) → opacity 1, translateY(0)`，320ms，同一条缓动曲线。
4. 两个动画同时开始。
5. 同一句话流式更新文字时不重播动画，只有换句时才播。

```css
@keyframes zyCaptionIn { from { opacity: 0; transform: translateY(12px) } to { opacity: 1; transform: none } }
@keyframes zyCaptionUp { from { transform: translateY(30px) } to { transform: none } }
.zy-caption-current { animation: zyCaptionIn .32s cubic-bezier(.2,.8,.2,1) both }
.zy-caption-prev    { animation: zyCaptionUp .32s cubic-bezier(.2,.8,.2,1) both }
```

用 React 的 `key` 绑定句子 id，换句时重新挂载，动画自然重播。

### 4.5 字幕什么时候消失

- 有人在说话（任何一方的字幕还在更新），字幕一直显示。
- 双方都停下来 **4 秒** 后，整个字幕区域淡出：`opacity 1 → 0`，500ms ease。
- 淡出后有人再开口：字幕区域立刻恢复（`opacity 1`，同样 500ms），新的一句按 4.4 出现。这时不显示淡出前的上一句，只显示新句。
- 4 秒做成常量 `CAPTION_IDLE_HIDE_MS = 4000`，方便以后调。

## 6. 通话流程

### 6.1 自动开始

- 打开人物窗口后自动调用 `start()`，不需要用户先点麦克风。
- 连接中：
  - 胶囊显示「连接中」（见第 2 节）；
  - 字幕区显示一行 15px `rgba(255,255,255,.62)`「正在接通…」；
  - 麦克风按钮不可点，挂断可以点（取消连接）。
- 连上后就可以直接说话。

### 6.2 错误

- 删掉旧的右上角状态文字。错误统一显示在字幕区当前句的位置：
  - 15px，颜色 `#FFC8BD`；
  - 文字用现有的 `microphoneError` / `fail` 文案。
- 麦克风权限被拒时，错误下面放一个按钮「打开系统麦克风设置」：
  - 样式同「再打给她」，高 36px；
  - 点击走现有的 `openMicrophoneSettings`。
- 摄像头权限被拒时：
  - 摄像头按钮保持关闭；
  - 字幕区提示「智域没有摄像头权限，请在系统设置里允许后重试」，下面放按钮「打开系统摄像头设置」（新增 `openCameraSettings`，见 6.3）；
  - 不影响语音通话。
- 服务端 `notice`：在字幕区当前句位置显示 3 秒，样式同用户字幕，然后恢复正常字幕。

### 6.3 摄像头权限（Electron）

- 主进程：
  - 人物窗口的 `session.setPermissionRequestHandler` 放行 `media` 里的 video；
  - macOS 上调用 `systemPreferences.askForMediaAccess('camera')`；
  - `Info.plist` 加 `NSCameraUsageDescription`：「智域需要使用摄像头，在视频通话时显示你自己的画面」。
- `desktop-bridge.ts` 加 `openCameraSettings()`：
  - macOS 打开 `x-apple.systempreferences:com.apple.preference.security?Privacy_Camera`；
  - Windows 打开 `ms-settings:privacy-webcam`。
- 摄像头用单独的 `getUserMedia({ video: { width: 1280, height: 720 } })`，不要和麦克风的流混在一起，免得关摄像头时把麦克风也停了。
