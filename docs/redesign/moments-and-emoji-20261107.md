# 朋友圈、看图与表情面板（2026-11-07）

按用户最新图片反馈调整现有界面，保留原账号、消息、人物素材与普通聊天发送键。

- 圆头像单独占左侧；右侧依次显示姓名与状态、文案、图片、时间地点、互动。24小时内显示经过的分钟/小时，24小时起显示上海时区的月日；地点沿用发布时的可选输入。无有效时间不虚构。
- 点赞和评论共用更浅的灰色区域。自己已点赞或已评论时用实心图标，色彩使用Logo中取样的珊瑚橙到莓红；保留原按钮尺寸与间距。
- 朋友圈图片在当前App整窗透明磨砂浮层中打开，右上复制和关闭，左右切换，同一条动态内多图用底部实心/空心圆点标记。原图经内存画布转换PNG后写剪贴板，加载失败或复制失败显示实际结果；普通聊天的独立图片查看器与联系人头像预览保留。
- 评论底部只留表情和发送，空内容灰色不可发送，有文字或表情后用现有雾蓝色；真正发送成功才收起，失败保留草稿，迟到回执不关闭新草稿。
- 两个表情面板都只显示完整目录的表情，8列、20px基础字号，可滚动。评论表情使用现有资料玻璃色与透明模糊；普通聊天表情纯白底。标题、搜索、顶部标签和关闭图标不再占位置，点击外侧或Escape仍可关闭。收藏表情数据不删除。

验证使用一次性账号与合成动态隔离正式写入；真实App只做只读浏览和用户要求的复制操作，不发送测试评论或打开摄像头/麦克风。

## 追加：所有人物共用通话结构

所有有效人物统一使用小满已有的满画面通话结构、顶部状态和底部控制位，各人物素材保留。AI提示从独立占高的白底条移到画面底部，透明底、白色文字，不改macOS原生窗口按钮。小满现有的显式打开通话后启动语音、静音、挂断和独立摄像头授权流程保持；尚未接通实时语音的人物明确提示可到聊天页交流，麦克风与摄像头不伪造已开启，也不接入别人的语音上下文。普通聊天仍可使用原文字输入和发送键。
